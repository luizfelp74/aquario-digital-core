# Aquário Digital

## Missão: Protocolo de Versionamento e Gestão de Ecossistema

Este repositório simula o fluxo de desenvolvimento corporativo de um sistema de monitoramento de aquário digital, praticando conceitos de controle de versão com Git e GitHub.

## Ambientes (Branches)

- **`develop`** — Ambiente de desenvolvimento. É onde novas funcionalidades são criadas e integradas antes de seguirem para testes.
- **`stage`** — Ambiente de homologação/testes. Recebe as funcionalidades já integradas na `develop` para validação antes de irem para produção.
- **`main`** — Ambiente de produção. Contém a versão estável e validada do sistema.
